## When a crew helps

A recording-to-multiple-formats job has distinct editing, visual, and fact-checking tasks. For a single short post, Writer and a person's review may be enough.

## Bring these inputs

Approved source and audience, transcript or recording, brand references, target channels and sizes, content rights, and publication owner.

## Set up and run

1. Select only the roles this job needs. Existing role links lead to Cabinet's current setup pages; new role links contain full manual-test instructions.
2. Put each selected role in its own conversation or Bot. Paste the new role's Role instructions section, or add the task extension below to an existing role. These files are not native import archives or add-to-app links.
3. Start with the fictional first task below. Supply the same approved source records to each role that needs them. A copied handoff alone is not evidence for a factual claim.
4. Pass reviewed results in the order below. If your app lacks Bot-to-Bot handoff, copy the small handoff yourself. Do not assume a shared folder, tool connection, or group conversation creates separate security boundaries.
5. Record each actual answer and failed attempt. Review before connecting real accounts or adding a schedule. Set read-only access and service-side cost caps where available; these written limits cannot enforce a billing cap.

## Who passes what to whom

1. Story identifies the approved message and evidence.
2. Writer drafts text while Clip Planner prepares an edit list and Visual Producer prepares a visual brief.
3. Editor checks all versions against the original source and brand examples.
4. The person approves rendering, uploading, and publication where applicable.

## Task extensions for existing Bots

### Story

Keep the existing Bot's role and boundaries. For this crew: Choose a clear message from the approved facts. Find a clear central message in confirmed facts. Preserve important qualifications and distinguish evidence from aspirations. Use only the input assigned to you for this task. Return the result, supporting records, unresolved questions, and next owner. A handoff does not approve an external action.

### Writer

Keep the existing Bot's role and boundaries. For this crew: Draft the main piece and channel versions. Draft for the named audience using the approved brief. Preserve meaning and claims; never invent quotations or evidence. Keep drafts unsent. Use only the input assigned to you for this task. Return the result, supporting records, unresolved questions, and next owner. A handoff does not approve an external action.

### Editor

Keep the existing Bot's role and boundaries. For this crew: Check meaning, claims, voice, and rights before publication. Check the draft against its original sources, audience, and voice. Flag unsupported claims and rights concerns. Return specific revisions without publishing. Use only the input assigned to you for this task. Return the result, supporting records, unresolved questions, and next owner. A handoff does not approve an external action.

## First task

Fictional source at 00:10-00:40: three customers tried a mock-up and none paid. Audience: independent tutors. Prepare a short post, one clip plan keeping both facts, and a 1200 by 630 thumbnail brief using dark green, cream, and brass. No video or image tool is supplied.

## Check the result

- Every version keeps the unpaid-customer qualification.
- Clip timestamps come from the supplied source.
- Visuals follow the brand and serve this subject.
- No brief is represented as a finished image or video; nothing is published.

Save the app, model if shown, date, answers, actual external actions, and pass/fail/not-checked against each item. A written checklist or a favorable review does not prove a runtime pass.

## Limits for this sample

One approved source; three text drafts; two clip choices; two visual concepts. No content schedule or render until approved.

Stop when the task finishes, a required input is missing, a tool fails, or an action needs new approval. No automatic retries. No new credentials, private connectors, external messages, purchases, publishing, or deployment are part of the sample.

## Finished output

A main message, post drafts, edit list, visual brief, and final review.
