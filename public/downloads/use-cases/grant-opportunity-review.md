# Grant opportunity review

Designed for: Nonprofits and public organizations deciding which funding opportunities deserve time

Result: A ranked opportunity list with eligibility checks, deadlines, fit, and next steps.

## Bots

1. Scout
2. Researcher
3. Planner

## Information to gather

- Organization profile and priorities
- Approved grant sources
- Capacity, geography, and deadline rules

## Workflow

### 1. Scout

Find opportunities that match the search rules

Output: A short candidate list

Message to send:

Use the approved inputs I provide. Find opportunities that match the search rules. Return this result: A short candidate list. Ask me about missing information before you continue.

### 2. Researcher

Check eligibility, deadline, and stated requirements

Output: An opportunity comparison

Message to send:

Start with this result from Scout: A short candidate list. Check eligibility, deadline, and stated requirements. Return this result: An opportunity comparison. Ask me about missing information before you continue.

### 3. Planner

Estimate the work and map the decision timeline

Output: A recommended pursuit plan

Message to send:

Start with this result from Researcher: An opportunity comparison. Estimate the work and map the decision timeline. Return this result: A recommended pursuit plan. Ask me about missing information before you continue.

## Overall request

Review these grant opportunities against our approved profile. Report eligibility, deadline, required match, likely work, source link, and any question that needs confirmation.

## Decisions for a person

- Confirm eligibility with the funder when necessary
- Choose which opportunities to pursue
- Approve the application plan and commitments

## First test

Review three closed or low-priority opportunities and compare the results with the original funder pages.

## Hermes Desktop setup

1. Open each Bot's page in Bot Cabinet's Hermes Bots collection and follow its manual Hermes Desktop setup steps.
2. Run each step in that Bot's own chat and review the result.
3. Pass the approved result to the next Bot with the message provided for that step.
4. After the sequence works, you may create a group with the same Bots.
5. In a group, @mention the Bot you want. Membership order does not control who responds.
