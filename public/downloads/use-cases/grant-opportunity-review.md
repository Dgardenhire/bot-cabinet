# Grant opportunity review

Designed for: Nonprofits and public organizations deciding which funding opportunities deserve time

Result: A ranked opportunity list with eligibility checks, deadlines, fit, and next steps.

## Operating guide

- **When to use it:** Use this workflow when you need a ranked opportunity list with eligibility checks, deadlines, fit, and next steps.
- **Lead Bot:** Researcher
- **Cadence:** When a person supplies the approved brief and starts the workflow
- **Typical first run:** 15–30 minutes for a first manual run

### Access for the first run

- The approved inputs listed on this page
- Only the files, sources, and services required for this run
- No sending, publishing, spending, or live-system changes without approval

## Recommended starting Bot

1. Researcher

One Researcher can review a short grant list. Add Scout only for a broad recurring search, or Planner after you decide to pursue a complicated application.

Optional specialists: scout, planner.

## Information to gather

- Organization profile and priorities
- Approved grant sources
- Capacity, geography, and deadline rules

## Workflow

### 1. Researcher

Find or review the supplied opportunities, check eligibility and deadlines, compare fit, and outline the next decision

Output: A ranked opportunity list with source links, requirements, open questions, and a recommended next step

Message to send:

Use the approved inputs I provide. Find or review the supplied opportunities, check eligibility and deadlines, compare fit, and outline the next decision. Return this result: A ranked opportunity list with source links, requirements, open questions, and a recommended next step. Ask me about missing information before you continue.

## Overall request

Review these grant opportunities against our approved profile. Report eligibility, deadline, required match, likely work, source link, and any question that needs confirmation.

## Decisions for a person

- Confirm eligibility with the funder when necessary
- Choose which opportunities to pursue
- Approve the application plan and commitments

## First test

Review three closed or low-priority opportunities and compare the results with the original funder pages.

## Success checkpoint

The first run passes when a person can verify the final result against the supplied material and every decision listed below remains with that person. Review three closed or low-priority opportunities and compare the results with the original funder pages.

## If the workflow stalls

If the result is incomplete, mark the missing information and ask the same Bot to correct it. Add another Bot only when a genuinely separate role or independent check would help.

## Hermes Desktop setup

1. Open the linked Bot's page, download its .tar.gz profile, and import it from the Profiles screen in Hermes Desktop.
2. Review the profile's SOUL.md, Bot Passport, and requested access.
3. Run the complete request in that Bot's chat with low-risk material and review the result.
4. Add a schedule, outside connection, or optional specialist only after the manual version works.
