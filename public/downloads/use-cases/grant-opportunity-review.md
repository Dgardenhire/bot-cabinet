# Grant opportunity review

Designed for: Nonprofits and public organizations deciding which funding opportunities deserve time

Result: A ranked opportunity list with eligibility checks, deadlines, fit, and next steps.

## Operating guide

- **When to use it:** Use this workflow when you need a ranked opportunity list with eligibility checks, deadlines, fit, and next steps.
- **Lead Bot:** Scout
- **Cadence:** When a person supplies the approved brief and starts the workflow
- **Typical first run:** 30–60 minutes for a first manual run

### Access for the first run

- The approved inputs listed on this page
- Only the files, sources, and services required for this run
- No sending, publishing, spending, or live-system changes without approval

## Bots

1. Scout
2. Researcher
3. Planner

## Information to gather

- Organization profile and priorities
- Approved grant sources
- Capacity, geography, and deadline rules

## Workflow

### 1. Scout

Find opportunities that match the search rules

Output: A short candidate list

Message to send:

Use the approved inputs I provide. Find opportunities that match the search rules. Return this result: A short candidate list. Ask me about missing information before you continue.

### 2. Researcher

Check eligibility, deadline, and stated requirements

Output: An opportunity comparison

Message to send:

Start with this result from Scout: A short candidate list. Check eligibility, deadline, and stated requirements. Return this result: An opportunity comparison. Ask me about missing information before you continue.

### 3. Planner

Estimate the work and map the decision timeline

Output: A recommended pursuit plan

Message to send:

Start with this result from Researcher: An opportunity comparison. Estimate the work and map the decision timeline. Return this result: A recommended pursuit plan. Ask me about missing information before you continue.

## Handoff rules

1. Scout hands the approved output—a short candidate list—to Researcher.
2. Researcher hands the approved output—an opportunity comparison—to Planner.

## Overall request

Review these grant opportunities against our approved profile. Report eligibility, deadline, required match, likely work, source link, and any question that needs confirmation.

## Decisions for a person

- Confirm eligibility with the funder when necessary
- Choose which opportunities to pursue
- Approve the application plan and commitments

## First test

Review three closed or low-priority opportunities and compare the results with the original funder pages.

## Success checkpoint

The first run passes when a person can verify the final result against the supplied material and every decision listed below remains with that person. Review three closed or low-priority opportunities and compare the results with the original funder pages.

## If the workflow stalls

If a handoff is incomplete, return it to the Bot that produced it with the missing information marked. Do not move to the next Bot until a person approves the corrected result.

## Hermes Desktop setup

1. Open each Bot's page, download its .tar.gz profile, and import it from the Profiles screen in Hermes Desktop.
2. Review each imported profile's SOUL.md, Bot Passport, and requested access.
3. Run each step in that Bot's own chat and review the result.
4. Pass the approved result to the next Bot with the message provided for that step.
5. After the sequence works, you may create a group with the same Bots. In a group, @mention the Bot you want.
