# Social media content set

Designed for: Small organizations and professionals who need several posts from one approved idea

Result: Draft posts that carry one approved message across selected platforms, with source links and review notes.

## Operating guide

- **When to use it:** Use this workflow when you need draft posts that carry one approved message across selected platforms, with source links and review notes.
- **Lead Bot:** STORY
- **Cadence:** When a person supplies the approved brief and starts the workflow
- **Typical first run:** 30–60 minutes for a first manual run

### Access for the first run

- The approved inputs listed on this page
- Only the files, sources, and services required for this run
- No sending, publishing, spending, or live-system changes without approval

## Bots

1. STORY
2. Writer
3. Editor

## Information to gather

- The approved idea or announcement
- Audience and platforms
- Confirmed facts, source material, and voice examples

## Workflow

### 1. STORY

Build a central message from the confirmed facts

Output: A message brief with proof points and unsupported claims marked

Message to send:

Use the approved inputs I provide. Build a central message from the confirmed facts. Return this result: A message brief with proof points and unsupported claims marked. Ask me about missing information before you continue.

### 2. Writer

Adapt the approved message for each platform

Output: A set of draft posts with source notes

Message to send:

Start with this result from STORY: A message brief with proof points and unsupported claims marked. Adapt the approved message for each platform. Return this result: A set of draft posts with source notes. Ask me about missing information before you continue.

### 3. Editor

Remove repetition and check tone

Output: A revised content set with questions

Message to send:

Start with this result from Writer: A set of draft posts with source notes. Remove repetition and check tone. Return this result: A revised content set with questions. Ask me about missing information before you continue.

## Handoff rules

1. STORY hands the approved output—a message brief with proof points and unsupported claims marked—to Writer.
2. Writer hands the approved output—a set of draft posts with source notes—to Editor.

## Overall request

Create three social media drafts from this approved announcement. Establish one central message from the confirmed facts, adapt it to each platform, and list every claim or wording choice that needs approval.

## Decisions for a person

- Approve the central message and proof points
- Approve names, quotations, and public claims
- Schedule or publish each post

## First test

Create three posts from one approved announcement and review them beside recent posts from the same account.

## Success checkpoint

The first run passes when a person can verify the final result against the supplied material and every decision listed below remains with that person. Create three posts from one approved announcement and review them beside recent posts from the same account.

## If the workflow stalls

If a handoff is incomplete, return it to the Bot that produced it with the missing information marked. Do not move to the next Bot until a person approves the corrected result.

## Hermes Desktop setup

1. Open each Bot's page, download its .tar.gz profile, and import it from the Profiles screen in Hermes Desktop.
2. Review each imported profile's SOUL.md, Bot Passport, and requested access.
3. Run each step in that Bot's own chat and review the result.
4. Pass the approved result to the next Bot with the message provided for that step.
5. After the sequence works, you may create a group with the same Bots. In a group, @mention the Bot you want.
