# Unstick Me — Gets you started on a task you keep avoiding

Asks short questions, one at a time, until you take the first small step on a stalled task, or pick an honest alternative such as a rough version, a new time or asking for help.

Inspired by Yanqing Cheng's Unstick me (Grok Bot): https://x.ai/bot/EahHaI-kwO0hgWj6I45jC

This LINCHPIN starter package contains profile metadata, role instructions, a Bot Passport, setup documentation, a package manifest, and a license.

## What this download is

The .tar.gz download is a Hermes profile archive. Import it from the Profiles screen in Hermes Desktop, or use the terminal command shown on this Bot's page. The ZIP contains the same readable source files for inspection.

## Who this helps

Anyone stuck at the start of a task, including people who deal with procrastination, ADHD or task paralysis.

## Good first requests

- I need to start my expense report and I keep putting it off. Help me begin.
- I have 20 minutes before my next meeting. Get me moving on the proposal draft.
- I've been avoiding a hard email for three days. Help me take one step on it.

## Intended output

- One small first step you can do in the next few minutes
- An honest alternative if starting now isn't realistic: a rough version, a new time or a person to ask
- A one-line note of what you chose, so you can pick it up later

## Setup information to provide

- The task you're stuck on, in your own words
- How much time and energy you have right now
- Anything that makes this task harder than it looks

## Tools and connections to review in Hermes Desktop

- None required. It works entirely in the conversation.

Select these tools and connections only when the job requires them. Read every skill and review every outside connection before enabling it.

## Human approval points

- Ask one short question at a time. Never answer with a long plan or a list of steps.
- Treat a rough version, a new time or asking for help as real choices, not failures. Don't lecture or shame.
- This is not therapy or medical advice. If the person describes a crisis or talks about harming themselves, stop the exercise and point them to a person or crisis line who can help.

## Set it up in Hermes Desktop

1. Import the .tar.gz profile archive in Hermes Desktop, or run the import command shown on this Bot's page.
2. Open the imported profile and review its name, description, and SOUL.md role instructions.
3. Select only the skills, tools, and connections listed above that your version of this job needs.
4. Begin with this test: Say you have been avoiding a two-paragraph email to a colleague for three days. It should ask one question at a time, reach a first step you can do in two minutes, and offer a rough version, new time or asking for help if you say you can't start now.
