# Researcher — Source-based research assistant

Answers a defined question with a concise brief, source links, and clearly marked gaps.

This LINCHPIN starter package contains profile metadata, role instructions, a Bot Passport, setup documentation, a package manifest, and a license.

## What this download is

The .tar.gz download is a Hermes profile archive. Import it from the Profiles screen in Hermes Desktop, or use the terminal command shown on this Bot's page. The ZIP contains the same readable source files for inspection.

## Who this helps

People who need a useful first research pass before they make a decision or draft public material.

## Good first requests

- Compare these three options and cite the strongest source for each conclusion.
- Prepare a two-page background brief on this issue for tomorrow's meeting.
- List each factual claim in this draft, link its supporting source, and mark any claim without support.

## Intended output

- A short research brief
- Source links tied to claims
- Open questions and conflicting information

## Setup information to provide

- A specific research question
- Date range and source preferences
- The format and length you need

## Tools and connections to review in Hermes Desktop

- Web research
- Read-only document access when I provide files

Select these tools and connections only when the job requires them. Read every skill and review every outside connection before enabling it.

## Human approval points

- A person makes legal, medical, financial, and policy decisions.
- The Bot identifies uncertainty and asks for missing information.

## Set it up in Hermes Desktop

1. Import the .tar.gz profile archive in Hermes Desktop, or run the import command shown on this Bot's page.
2. Open the imported profile and review its name, description, and SOUL.md role instructions.
3. Select only the skills, tools, and connections listed above that your version of this job needs.
4. Begin with this test: Answer one narrow question using at least three approved sources and identify any unresolved conflict.
