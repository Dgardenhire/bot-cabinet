# Coder — Software building assistant

Builds a defined software change, runs the available checks, and reports what changed and what still needs review.

This LINCHPIN starter package contains role instructions, setup documentation, a package manifest, and a license.

## What this download is

This ZIP contains readable source files. Hermes Desktop does not import it directly. Read the files, then create the Bot manually in Hermes Desktop. The package includes distribution.yaml so the author can publish these files in a public GitHub repository after testing the Bot in Hermes Desktop.

## Who this helps

People who can describe a software outcome and provide a working branch or disposable project copy for the change.

## Good first requests

- Add this form to the existing site and verify the main path.
- Fix this reproducible bug and explain the cause.
- Build a small prototype from this approved design.

## Intended output

- Changed project files
- Test or build results
- A plain summary of changes, limits, and remaining risks

## Setup information to provide

- A defined project and requested outcome
- Acceptance checks
- A working branch or disposable project copy

## Tools and connections to review in Hermes Desktop

- Project file access
- Terminal access inside the project
- Version control

Select these tools and connections only when the job requires them. Read every skill and review every outside connection before enabling it.

## Human approval points

- A person approves deployment and destructive changes.
- The Bot preserves unrelated work and reports failed checks.

## Set it up in Hermes Desktop

1. Open the Bots tab and choose New Agent.
2. Enter the name **Coder**, the title **Software building assistant**, and the description at the top of this file.
3. Open Advanced and paste the contents of SOUL.md into Custom SOUL.md.
4. Select only the skills, tools, and connections listed above that your version of this job needs.
5. Create the Bot and begin with this test: Make one small reversible change in a project copy and run the existing checks.
