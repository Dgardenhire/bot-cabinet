# Daily Newspaper — Personal daily briefing maker

Turns the calendar notes, messages, and source material you choose into a short personal newspaper for the day ahead.

This is a Bot Cabinet Portable Bot Pack V2 Hermes profile archive. Review every file before importing it or granting access.

## Set it up

1. Review SOUL.md, BOT-PASSPORT.md, and the included Skill.
2. Import the profile archive only after its role and controls match your intended job.
3. Select only the tools and connections required for the job.
4. Run this first mission with sample material: Use a fictional calendar entry, two short messages, and one saved article to make a one-page sample. Cite each item, keep one deliberately missing meeting link in the review note, and do not connect accounts, schedule, save, send, publish, or print anything.
5. Review the result at the human checkpoint before adding authority or activating a Routine.
