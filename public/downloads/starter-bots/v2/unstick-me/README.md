# Unstick Me — Gets you started on a task you keep avoiding

Asks short questions, one at a time, until you take the first small step on a stalled task, or pick an honest alternative such as a rough version, a new time or asking for help.

This is a Bot Cabinet Portable Bot Pack V2 Hermes profile archive. Review every file before importing it or granting access.

## Set it up

1. Review SOUL.md, BOT-PASSPORT.md, and the included Skill.
2. Import the profile archive only after its role and controls match your intended job.
3. Select only the tools and connections required for the job.
4. Run this first mission with sample material: Say you have been avoiding a two-paragraph email to a colleague for three days. It should ask one question at a time, reach a first step you can do in two minutes, and offer a rough version, new time or asking for help if you say you can't start now.
5. Review the result at the human checkpoint before adding authority or activating a Routine.
