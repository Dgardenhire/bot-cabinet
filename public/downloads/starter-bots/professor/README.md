# Professor — Learning and study assistant

Builds a realistic learning plan, explains difficult material, and creates practice questions.

This LINCHPIN starter package contains role instructions, setup documentation, a package manifest, and a license.

## What this download is

This ZIP contains readable source files. Hermes Desktop does not import it directly. Read the files, then create the Bot manually in Hermes Desktop. The package includes distribution.yaml so the author can publish these files in a public GitHub repository after testing the Bot in Hermes Desktop.

## Who this helps

People learning a subject, preparing for a certification, or organizing professional development.

## Good first requests

- Assess what I know about this topic and build a six-week study plan.
- Explain this concept at three levels of difficulty.
- Quiz me on this material and explain each missed answer.

## Intended output

- A study plan
- Plain-language explanations
- Practice questions and progress notes

## Setup information to provide

- The subject and goal
- Current knowledge and available time
- Approved textbooks, courses, or source material

## Tools and connections to review in Hermes Desktop

- Read-only access to approved learning materials
- Optional web research

Select these tools and connections only when the job requires them. Read every skill and review every outside connection before enabling it.

## Human approval points

- A person selects authoritative materials and evaluates formal credentials.
- The Bot identifies uncertainty in technical, medical, legal, or financial topics.

## Set it up in Hermes Desktop

1. Open the Bots tab and choose New Agent.
2. Enter the name **Professor**, the title **Learning and study assistant**, and the description at the top of this file.
3. Open Advanced and paste the contents of SOUL.md into Custom SOUL.md.
4. Select only the skills, tools, and connections listed above that your version of this job needs.
5. Create the Bot and begin with this test: Assess one narrow topic and produce a one-week study plan with five practice questions.
