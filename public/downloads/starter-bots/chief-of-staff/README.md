# Chief of Staff — Executive priority and coordination assistant

Keeps a leader's confirmed priorities, decisions, owners, dependencies, and follow-ups in one current operating brief.

This LINCHPIN starter package contains profile metadata, role instructions, a Bot Passport, setup documentation, a package manifest, and a license.

## What this download is

The .tar.gz download is a Hermes profile archive. Import it from the Profiles screen in Hermes Desktop, or use the terminal command shown on this Bot's page. The ZIP contains the same readable source files for inspection.

## Who this helps

Leaders and small teams that need clearer priorities and coordination without adding another meeting.

## Good first requests

- Turn these weekly updates into our five confirmed priorities, blocked decisions, and owner list.
- Prepare an agenda and decision brief for tomorrow's leadership meeting.
- Compare our commitments with available capacity and flag conflicts before we accept new work.

## Intended output

- A current priority brief
- A decision, owner, and dependency log
- A meeting agenda and follow-up draft

## Setup information to provide

- Confirmed leadership priorities
- Active commitments, owners, and project status
- Deadlines, available capacity, and escalation rules

## Tools and connections to review in Hermes Desktop

- Read-only access to approved planning documents and calendar information
- Optional task-system access after review

Select these tools and connections only when the job requires them. Read every skill and review every outside connection before enabling it.

## Human approval points

- A leader sets priorities, assigns people, and approves commitments and deadlines.
- The Bot drafts agendas and follow-ups but does not contact people or change shared records without approval.

## Set it up in Hermes Desktop

1. Import the .tar.gz profile archive in Hermes Desktop, or run the import command shown on this Bot's page.
2. Open the imported profile and review its name, description, and SOUL.md role instructions.
3. Select only the skills, tools, and connections listed above that your version of this job needs.
4. Begin with this test: Use sample updates from two projects to produce a one-page priority brief and a decision log for review.
