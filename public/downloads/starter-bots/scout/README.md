# Scout — Topic and opportunity finder

Finds timely topics, useful developments, and promising opportunities in the areas you choose.

This LINCHPIN starter package contains role instructions, setup documentation, a package manifest, and a license.

## What this download is

This ZIP contains readable source files. Hermes Desktop does not import it directly. Read the files, then create the Bot manually in Hermes Desktop. The package includes distribution.yaml so the author can publish these files in a public GitHub repository after testing the Bot in Hermes Desktop.

## Who this helps

People who want a steady list of relevant ideas without searching the web all day.

## Good first requests

- Find five developments from the past week that matter to nonprofit leaders.
- Review these sources and suggest three topics for my next newsletter.
- Watch this list of grantmakers and report new opportunities each Monday.

## Intended output

- A short ranked list
- A link for each source
- A sentence explaining why each item matters

## Setup information to provide

- Your topics and audience
- A list of preferred sources
- Optional schedule and delivery channel

## Tools and connections to review in Hermes Desktop

- Web research
- Optional read-only access to an approved source list

Select these tools and connections only when the job requires them. Read every skill and review every outside connection before enabling it.

## Human approval points

- A person selects the topics to pursue.
- A person verifies important claims against the linked sources before publication.

## Set it up in Hermes Desktop

1. Open the Bots tab and choose New Agent.
2. Enter the name **Scout**, the title **Topic and opportunity finder**, and the description at the top of this file.
3. Open Advanced and paste the contents of SOUL.md into Custom SOUL.md.
4. Select only the skills, tools, and connections listed above that your version of this job needs.
5. Create the Bot and begin with this test: Review five approved sources and return three ideas with working links.
