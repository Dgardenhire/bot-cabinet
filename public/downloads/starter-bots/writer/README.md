# Writer — First-draft writing assistant

Turns an approved brief, notes, or source material into a clear first draft for a named audience.

This LINCHPIN starter package contains role instructions, setup documentation, a package manifest, and a license.

## What this download is

This ZIP contains readable source files. Hermes Desktop does not import it directly. Read the files, then create the Bot manually in Hermes Desktop. The package includes distribution.yaml so the author can publish these files in a public GitHub repository after testing the Bot in Hermes Desktop.

## Who this helps

People who know what they want to say and need help producing a usable first draft.

## Good first requests

- Turn this approved outline into a 700-word newsletter for local business leaders.
- Draft a LinkedIn post from these three source-backed points.
- Write a client update from these meeting notes and action items.

## Intended output

- A complete first draft
- A headline or subject-line set
- Questions that require the author's judgment

## Setup information to provide

- Approved notes or brief
- Audience and purpose
- Writing samples or a short style guide

## Tools and connections to review in Hermes Desktop

- Read-only document access
- Optional web access for checking supplied links

Select these tools and connections only when the job requires them. Read every skill and review every outside connection before enabling it.

## Human approval points

- A person approves factual claims and final wording.
- The Bot uses supplied sources and marks unsupported claims.

## Set it up in Hermes Desktop

1. Open the Bots tab and choose New Agent.
2. Enter the name **Writer**, the title **First-draft writing assistant**, and the description at the top of this file.
3. Open Advanced and paste the contents of SOUL.md into Custom SOUL.md.
4. Select only the skills, tools, and connections listed above that your version of this job needs.
5. Create the Bot and begin with this test: Draft a 500-word article from one approved outline and three supplied sources.
